# Сжатие без потери качества

Веб-приложение для сжатия изображений и DOCX-файлов без видимой потери качества. Работает полностью в браузере — никакой загрузки на сервер.

## Возможности

- **Сжатие изображений:** AVIF, WebP, PNG, JPG
- **Сжатие DOCX:** оптимизация изображений внутри Word-документов
- **Тёмная тема:** удобная работа в любое время суток
- **100% конфиденциальность:** файлы обрабатываются локально и не покидают ваш компьютер

## Как это работает

### Сжатие изображений

Приложение использует HTML5 Canvas API для оптимизации изображений:

- **Масштабирование:** если изображение больше 2000 px по любой стороне, оно уменьшается с сохранением пропорций.
- **Квантование цветов:** алгоритм уменьшает количество цветов до 256, группируя похожие оттенки.
- **Конвертация в WebP:** для изображений не в формате PNG/GIF используется формат WebP с качеством 80%.
- **Сравнение:** если сжатое изображение больше исходного, сохраняется оригинал.

### Сжатие DOCX

DOCX — это ZIP-архив с XML и медиафайлами внутри. Алгоритм:

1. **Распаковка:** DOCX распаковывается как ZIP-архив с помощью JSZip.
2. **Поиск изображений:** находятся изображения PNG, JPG, JPEG, GIF, WebP, BMP и TIFF.
3. **Оптимизация:** каждое изображение масштабируется до 1200 px и пересохраняется в оптимизированном формате.
4. **Упаковка:** файл упаковывается обратно с максимальным уровнем сжатия DEFLATE.

## Технологии

- HTML5 — структура и Drag & Drop API
- JavaScript (ES6+) — логика приложения
- Canvas API — обработка и сжатие изображений
- JSZip — работа с DOCX как с ZIP-архивом

## Использование

### Запуск

Откройте `index.html` в любом современном браузере:

```powershell
start index.html
```

Или перетащите файл `index.html` в окно браузера.

### Как использовать

1. Перетащите файлы в область загрузки или нажмите **«Выбрать файлы»**.
2. Дождитесь завершения обработки.
3. Сжатые файлы автоматически загрузятся на ваш компьютер.
4. Просмотрите результаты сжатия и процент экономии.

## Результаты

Приложение показывает:

- исходный размер файла;
- размер после сжатия;
- процент экономии.

## Безопасность

- Все операции выполняются в браузере пользователя.
- Файлы не отправляются на сервер.
- Сторонние сервисы сжатия не используются.
- Данные остаются на вашем компьютере.

## Требования

- Современный браузер с поддержкой Canvas API (Chrome, Firefox, Edge или Safari).
- Для обработки DOCX требуется подключение к интернету для загрузки JSZip с CDN.
